# Scripta 思刻 · Markdown 编辑器

Scripta 思刻是一款 Markdown 编辑器。目前使用和迭代 Windows 桌面版，独立浏览器版暂时暂停使用和迭代。

## 仓库结构

- [`desktop/`](desktop/) 存放 Windows 桌面版项目和系统文件读写代码。
- [`web/`](web/) 存放桌面版使用的编辑器界面和独立浏览器版的启动入口。构建桌面版时会打包这里的界面文件。
- 笔记放在单独的仓库。通过 **文件 → 选择笔记仓库** 指定目录，桌面版会记住该位置。每个主题可在笔记仓库根目录单独建文件夹。笔记的图片放在同名 `.assets/` 目录，PDF 等参考材料放在同名 `.资料/` 目录。

笔记仓库可使用以下结构：

```text
主题/
├── 笔记.md
├── 笔记.assets/
└── 笔记.资料/
    └── 参考资料.pdf
```

## Windows 桌面版

桌面版使用系统文件对话框，可直接保存回打开的文件。运行需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。Windows x64 安装包可从 [GitHub Releases](https://github.com/zxyxm/Scripta/releases) 的 Assets 下载。

从源码构建桌面版需要 .NET 8 或更新的 SDK：

```powershell
dotnet publish desktop/Moye.csproj -c Release -r win-x64 --self-contained true -o dist/Scripta
```

启动 `dist/Scripta/Scripta.exe`。分发时请保留整个输出目录。

## 桌面版使用

- 在 **视图 → 显示设置** 中设置文档字号、编辑区最大宽度和默认启动窗口。输入字号和宽度时可实时预览，保存后保留，取消会恢复原值。启动窗口设置在下次打开时生效。
- 普通笔记可用一级至六级标题。合并多篇笔记时，每篇笔记以 H2 开头，原有下级标题随之调整。存在多个并列顶级标题或缺少明确文档标题时，以文件名作为 H2。
- 点击 **导入 PDF**，选择 PDF 和导出的 Markdown 文件名。可提取 WPS 等软件导出的文本、书签、链接和常见表格，图片保存在相邻的同名 `.assets/` 目录。纯扫描页保留为图片。导入需要 Python 和 PyMuPDF，可用 `python -m pip install pymupdf` 安装后者。
- **文件 → 打开**支持直接用系统阅读器打开 PDF。笔记中指向本地 PDF 的相对链接也可打开，模式 2 中按住 Ctrl 点击。
- **导入 → 导入 WPS 智能文档（DOCX）**将导出的 DOCX 保存为新 Markdown 笔记。标题从 H2 开始，保留大纲的父子关系，超过 H6 的层级归入 H6。列表、表格和超链接转成 Markdown，内嵌图片存入同名 `.assets/`。
- **导入 → 导入 PDF（带原页引用）**为每个导入页添加原页链接，并把原 PDF 的副本存入同名 `.assets/`。点击链接可在思刻里预览对应页，选中右侧文字后可把摘录和出处插在链接下方。原页预览需要 Python 和 PyMuPDF。扫描件可以查看页图。
- 在笔记列表多选后右键选择 **合并 Markdown…**，也可通过 **导入 → 合并 Markdown 笔记**选择文件。合并按文件名排序，结果保存为新文件。同名图床内按来源分目录，其他相对链接随保存位置调整。
- 打开 UTF-8 编码的 `.md`、`.markdown` 或 `.txt` 文档，并将编辑结果保存回原文件。
- 桌面版启动时默认进入 **模式 2**，可以直接在排版上编辑。正文里每个实际换行都单独成段，Enter 和 Shift+Enter 都可新起一段。悬停时可点击左侧段落柄，或用 Alt+Shift+M 打开当前段落的菜单，转换段落类型、在上下方插入正文段、复制 Markdown、剪切或删除。**模式 1** 点击段落编辑该段的 Markdown，按 Esc 恢复排版时保留普通换行。**源码**可编辑整份 Markdown。
- 支持 GitHub Flavored Markdown，包括表格、任务列表、删除线和围栏代码块。左侧大纲会随标题更新。大纲的箭头收起目录分支，模式 2 正文里标题旁的箭头折叠该章节。点目录标题可跳转，目标被折叠时会自动展开。
- 在模式 2 中悬停标题时，点击「整段编辑」会在章节旁打开随正文滚动的格式面板。批量升降标题或清除指定的行内格式时，正文会实时预览。点击「应用」保留修改，可按 Ctrl+Z 一次撤销。点击「取消」或按 Esc 放弃格式修改。
- 按住标题行上的「按住拖动整段」按钮，跟随插入线将标题及其下属内容移到同一篇笔记的其他位置。可按 Ctrl+Z 撤销移动。
- 独占一段的网址或链接可从块菜单转成 H1–H6，并输入显示标题。再次选择当前标题级别可改名。按住 Ctrl 并左击标题可打开原链接。
- 模式 2 常规粘贴大段文字时（至少 800 字符或 10 个非空行），会自动打开「整段编辑」，格式操作只影响本次粘贴的内容。取消窗口会保留原样粘贴的内容。
- 在模式 2 中右键单元格，可在当前行上下插入行、在当前列左右插入列，或删除行列。表头下方可以新增数据行，表头和最后一列保留。按 Ctrl+Z 可撤销。
- 在模式 2 中选中内容会弹出右侧操作台，可复制、加粗或设为斜体。选区有标题时可将标题整体升降一级，或统一设为 H1–H6。粘贴含标题的内容会自动选中本次粘贴的内容。可用 Alt+Shift+H 聚焦操作台。
- 编辑时自动保留本机草稿。切换到其他笔记、打开文件或新建文档时，桌面版会先将修改保存回原文件。未命名的草稿会提示选择保存位置，取消或保存失败时保留当前草稿。
- 编辑区大纲旁的 **打开图床** 和 **打开参考资料** 会在资源管理器打开当前笔记对应的文件夹。首次打开时自动创建目录。笔记树容量包含图床和资料，折叠时显示可浏览的笔记及资料文件数。
- 点击笔记树的搜索按钮或按 **Ctrl+Shift+F**，可搜索仓库中已保存笔记的文件名、章节标题和正文。用方向键选择结果，按回车跳转。
- 在笔记或文件夹上右键选择 **设置图标…**，可手动选择、更换或移除彩色图标。图标设置按仓库保存在本机。
- **本地刷新 / 间接拉取**。在仓库设置里绑定本地文件夹，再点「刷新本地笔记」。使用 GitHub Desktop、其他 Git 客户端或网盘时，先在外部工具同步同一个文件夹，再回思刻刷新。GitLab、Gitee 和普通本地文件夹也可使用此模式。
- **GitHub 直连**。已有 GitHub 克隆可直接绑定其本地文件夹，再点「直接拉取更新」。首次下载或新建绑定会在所选本地文件夹下创建与 GitHub 仓库同名的子文件夹，并把它设为当前笔记仓库。直连使用本机 Git 的凭据访问私有库。更新只接受快进，推送前请保存并提交笔记。
- 「GitHub 直连」中的「一键安装并配置 Git」会检测本机 Git。缺失时通过 Windows 的 WinGet 安装 Git for Windows，安装后可直接使用。
- 两种模式共用当前本地文件夹，切换本身不会同步、搬动文件或改写远程地址。GitHub Desktop 和思刻可以轮流同步同一份 GitHub 克隆。刷新时会保留编辑中的草稿，保存前会提示磁盘版本冲突。
- 笔记树支持右键定位、复制路径、重命名、移动和删除。拖放可移动笔记，按住 Ctrl 拖放可复制。同名图床和参考资料随笔记重命名、移动或复制。可从资源管理器把文件拖到笔记树的 `.资料` 文件夹，悬停时会自动展开。**提交**会根据笔记变更自动填写说明，确认后创建本地 Git 提交。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / Cmd + O | 打开文件 |
| F2 | 重命名笔记树中当前聚焦的笔记或文件夹 |
| Ctrl / Cmd + S | 保存文件 |
| Ctrl / Cmd + / | 在源码和上次使用的写作模式之间切换 |
| Ctrl / Cmd + 1–6、0 | 改为一级至六级标题、正文 |
| Ctrl / Cmd + B、I、K | 粗体、斜体、链接 |
| Ctrl / Cmd + Shift + [、] | 有序列表、无序列表 |
| Ctrl / Cmd + Shift + Q、K | 引用、代码块 |
| Ctrl / Cmd + N | 新建文件 |
| Ctrl / Cmd + Enter | 在写作模式中添加段落 |
| Esc | 完成当前段落编辑 |

## 项目修改核对

| 范围 | 当前状态 |
| --- | --- |
| 桌面界面 | 使用 Scripta 思刻名称和石刻图标。左侧是编辑菜单，右侧是仓库、提交、导入和导出，编辑区保留快捷新建和保存。浏览器独立版暂停迭代。 |
| 笔记管理 | 仓库树、右键菜单、笔记及文件夹重命名、拖放、图床随文件处理、自动填写本地提交说明均已接入。 |
| 编辑和恢复 | 段落、可视和源码三种模式可切换。已有笔记切换时保存回原文件，恢复的草稿保留原文件关联。普通笔记从二级标题开始。 |
| 导入与输出 | PDF 可直接打开或导入，Markdown 可导出副本或合并。合并时每篇笔记以 H2 开头。 |
